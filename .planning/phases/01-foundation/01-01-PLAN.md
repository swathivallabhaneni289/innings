<objective>
Lay the shared ground for a parallel build: an Expo Router app with five tabs, one JSON contract that both the app and the Go API code against, a token-based design system with a light and a dark theme, and a data layer that hides HTTP from screens.

Purpose: Phases 2 to 5 run as parallel sub-agents with strict file ownership. They can only work in parallel if the contract and the shared components are fixed first.
Output: A typechecking app shell, `docs/API.md`, the TS and Go contract files, the theme, the core components and `src/data/`.
</objective>
