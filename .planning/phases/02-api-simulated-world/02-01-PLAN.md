<objective>
Build a deterministic, believable cricket world so the whole app works without an API key: fixtures around server start in every state, live scores that move with the clock, results, real current playing XIs, 8 friends and 16 public fans with logs, predictions and replies, and an anonymous crowd for ratings and prediction splits.

Purpose: The app's loop (predict, watch, log, compare) needs matches in every state at any time of day. A simulation anchored to server start guarantees that.
Output: `internal/sim` implementing every method in `sim.go`, with tests.
</objective>
