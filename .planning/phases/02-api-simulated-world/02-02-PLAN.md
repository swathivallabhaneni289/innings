<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App to API | Untrusted JSON bodies and path ids from any client holding a guest token |

## Threat Register

| Threat | Mitigation |
|--------|------------|
| Oversized or malformed bodies | `http.MaxBytesReader` caps bodies at 1 MB; bad JSON gets 400 `bad-json` |
| Acting as another user | The user always comes from the token, never from the body; `DELETE /v1/logs/{id}` only deletes the caller's log |
| Late predictions | Lock checked on the server clock, not the app's |
| Guest token theft | Accepted for v1: tokens are bearer secrets with no expiry; email sign-in is v2 |
</threat_model>
